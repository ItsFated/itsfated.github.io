## 一、基础知识

> 只介绍对游戏平衡影响较大的核心元素。  
> 参考教程：[【2025】王者荣耀萌新纯新手零基础快速入门](https://www.bilibili.com/video/BV15aThz7ESH)

### 1. 基本术语

| 术语 | 含义 |
|------|------|
| **ADC** | 物理输出英雄（射手），如后羿、孙尚香 |
| **AP** | 法术输出英雄（法师），如甄姬、小乔 |
| **Carry** | 能带领团队获胜的核心输出位 |
| **Gank** | 打野或中单突袭边路抓人 |
| **蹭线** | 打野/辅助合理吃兵线加速发育 |
| **推塔** | 比击杀更重要，是游戏最终目标 |

---

### 2. 游戏设置建议

- **战斗选项**：开启「名字显示」「技能冷却小数」「技能标签」
- **操作选项**：
  - 开启「补刀+推塔键」
  - 「技能取消方式」设为「取消按键」

> ✅ 这些设置能显著提升操作精度与战场信息获取效率。

---

### 3. 英雄基础

- 每个英雄拥有 **3个主动技能 + 1个被动技能**
- 英雄定位由技能特性决定：

| 定位 | 特性 |
|------|------|
| **坦克** | 肉盾，能抗伤害（常带护盾、回血、减伤） |
| **战士** | 半肉，能抗能打（兼具输出与生存） |
| **刺客** | 高爆发，秒杀脆皮，但自身脆弱 |
| **法师** | 持续法术伤害，依赖技能输出 |
| **射手** | 持续物理伤害，依赖普攻输出 |
| **辅助** | 提供治疗、增益、控制或保护 |

---

### 4. 铭文系统

- 用于强化英雄基础属性（攻击、防御、吸血、移速等）
- 新手建议使用系统推荐铭文，后期再根据英雄定制

---

### 5. 分路与位置职责

| 位置 | 适合英雄类型 | 核心任务 | 注意事项 |
|------|----------------|--------|----------|
| **对抗路**（上单） | 坦克、战士 | 抗压守塔、控河蟹、支援团战 | 不轻易压线，防Gank；优先出防御装；带闪现/传送更安全 |
| **中路** | 法师 | 快速清线 → 拿线权 → 游走支援 | 清完兵立刻支援；团战站位靠后，避免被切 |
| **发育路**（下路） | 射手 + 辅助 | 平稳发育 → 推塔 → 中后期输出 | 绝不脸探草丛；活着比杀人重要 |
| **打野**（游走） | 刺客、战士 | 刷野 → 控Buff → Gank → 控龙 | 观察敌方打野动向；优先帮优势路；逆风可带线牵制 |
| **辅助** | 软辅/硬辅 | 保C位 or 开团 + 做视野 | 经济让给C位；前期保射手，中期跟团 |

## 二、常见英雄组合（情侣双排推荐）

- **发育路**：后羿 / 鲁班七号 → 务必搭配 **瑶 / 明世隐 / 张飞** 等强保人辅助  
- **打野配合**：虞姬前期较弱，可选 **孙悟空** 等打野帮抓对线  
- **中辅联动**：**安琪拉 + 瑶** —— 瑶附身提供护盾，安琪拉蹲草一套秒人  

---

## 三、常见打法（按位置）

### 🛡️ 对抗路
- **思路**：抗压守塔 → 控河蟹 → 利用传送阵支援  
- **代表英雄**：白起、吕布、夏侯惇、老夫子

### 🔥 中路
- **思路**：快清线 → 拿线权 → 游走支援  
- **代表英雄**：小乔、安琪拉、嬴政、甄姬

### ⚔️ 打野
- **思路**：规划开局 → 控Buff → 4级Gank → 控龙推节奏  
- **代表英雄**：孙悟空、兰陵王、赵云、镜

### ❤️ 辅助
- **思路**：开局保射/跟野 → 做视野 → 团战保C或开团  
- **代表英雄**：瑶、张飞、蔡文姬、牛魔

### 🏹 发育路
- **思路**：平稳发育 → 出核心装 → 站稳输出位  
- **代表英雄**：后羿、鲁班七号、虞姬、孙尚香

## 五、上分策略

> **核心理念**：  
> **胜率 = 70% 英雄选择 + 20% 节奏意识 + 10% 操作细节**

### 1. 选强势组合，练固定打法
- 优先选择 **高胜率 + 高容错 + 操作简单** 的组合
- 情侣推荐：
  - **明世隐 + 后羿 / 虞姬**
  - **瑶 + 鲁班七号 / 蒙犽**
  - **孙悟空 + 安琪拉**
  - **张飞 + 小乔**

### 2. 掌握三阶段节奏

| 阶段 | 时间 | 目标 | 行动原则 |
|------|------|------|----------|
| **前期** | 0~4分钟 | 稳发育，不送一血 | 守一塔 > 拿河蟹；不深入压线 |
| **中期** | 4~10分钟 | 推塔控龙，建立优势 | 清线即集合；拿暴君/主宰；团后转线推塔 |
| **后期** | 10分钟+ | 决胜团战，一波定胜负 | 双龙会占视野；C位站后排；高地未破就有翻盘机会 |

### 3. 精进路线

| 目标 | 训练方法 |
|------|--------|
| 提升熟练度 | 固定1~2英雄，连续打10局以上 |
| 培养节奏感 | 训练营练习Gank路线、拿龙时机 |
| 改善站位 | 回放死亡镜头，反思“这波能不能不死” |
| 学习高端思路 | 观看KPL选手第一视角（如Fly、一诺） |
