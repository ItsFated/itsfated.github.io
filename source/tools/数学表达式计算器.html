输入表达式

每行输入一个表达式，支持加减乘除、百分比、括号、幂运算和负数

示例:

288000 * (1+5%) / (1+2%+5%) = 282616.8224

288000 * (1+5%)^2 / (1+2%+5%)^2 = 277334.1418

288000 * (1+5%)^3 / (1+2%+5%)^3 = 272150.1394

288000 * (1+5%)^4 / (1+2%+5%)^4 = 267063.0761

288000 * (1+5%)^5 / (1+2%+5%)^5 = 262071.4472

-10 * (-5 + 2) = 30.0000

运算优先级说明:

1. 括号内的表达式优先计算

2. 幂运算 (^) 其次优先

3. 乘法 (*) 和除法 (/) 再次优先

4. 加法 (+) 和减法 (-) 最后计算

5. 百分比 (%) 被视为乘以 0.01

6. 支持负数和负数运算
